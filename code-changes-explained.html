How to read this page

Start with the story, then use the file details as reference.

The page is organized like a guided code review. It starts with the big picture, then explains each implementation theme in the order the ideas build on each other: remove PrimeNG, use Tailwind, add dark mode, redesign the layout, make it responsive, and clean up the code.

  1. 1 Read the overview first Use it to understand what changed before looking at individual files.
  2. 2 Follow the six themes in order Each theme explains the intent, the important files, and the practical effect.
  3. 3 Use the glossary and file index last They are lookup sections, similar to an appendix in technical documentation.

Angular and Tailwind terms are explained in plain language as they appear. When useful, the explanations compare frontend concepts to backend ideas like services, configuration, dependency removal, and typed DTOs.
